# GameHub

## O contexto
Atividade prática para a cadeira de DevOps e Integração Contínua. Alunos irão praticar as diversas práticas aprendidas durante o período, onde implementarão o processo de DevOps, com versionamentos, testes, builds e deploy. A ideia por trás de tudo é utilizar as ferramentas trabalhadas em aula para demonstrar um fluxo completo da construção de uma pipeline de desenvolvimento, além de trazer o processo de documentação. **Lembrando que DevOps não é uma ferramenta específica, mas uma maneira de organizar o desenvolvimento, a integração e a entrega do software**.

## O desafio

A equipe deverá desenvolver o GameHub, uma aplicação Web que permita ao usuário manter sua própria biblioteca de jogos.

A aplicação deverá apresentar os jogos cadastrados pelo usuário em uma interface visual organizada e permitir que novos jogos sejam adicionados por meio de uma janela modal.

O sistema deverá consultar uma API externa para auxiliar no preenchimento das informações do jogo. A aplicação deverá ser executada posteriormente dentro de um container Docker, permitindo que o sistema permaneça disponível enquanto o container estiver em execução.
